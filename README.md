# MenuTools

[Скачать](https://github.com/Friderluvsu/menutools/releases/latest) · [Разработка](DEVELOPMENT.md) · [Профиль автора](https://github.com/Friderluvsu)

Нативные утилиты для macOS в строке меню: конвертация медиа, мониторинг системы, буфер обмена и управление окнами.

**Swift 6 · AppKit · SwiftUI · macOS 14+**

## Возможности

- **Медиа:** видео, аудио, GIF и изображения с перетаскиванием файлов.
- **Система:** CPU, RAM, сеть, температура и управление вентиляторами.
- **Рабочий процесс:** история буфера обмена, временная полка файлов и управление окнами.
- **Быстрый доступ:** запрет сна, энергосбережение, сеть и лимиты AI-сервисов.

### Permute Media Converter (Замена Permute 4)
- **Drag & Drop:** Перетаскивайте видео, аудио или картинки прямо в окно утилиты.
- **Видео:**
  - `MP4 (H.264 Universal)` — совместимо со всеми устройствами.
  - `MP4 (HEVC / H.265)` — максимальное сжатие при сохранении качества.
  - `MOV (Apple ProRes)` — для монтажа и мастеринга.
  - `WebM (VP9)` / `MKV`.
  - **Пресеты сжатия:** для Discord (< 25MB), Telegram (< 50MB) или сбалансированное.
- **Аудио:**
  - Извлечение звуковой дорожки из любого видео в 1 клик.
  - Конвертация в `MP3 (320k / 192k)`, `M4A/AAC (256k)`, `WAV (Lossless)` и `FLAC (Lossless)`.
- **GIF Maker:**
  - Создание высококачественных GIF из видео через двухпроходную генерацию палитры FFmpeg (без артефактов и "лесенок").
  - Пресеты: 640px (24 FPS), 480px (15 FPS), 320px (12 FPS), Original (30 FPS).
- **Изображения:**
  - Быстрая конвертация и сжатие: `WebP`, `PNG`, `JPG (90% / 70%)`, `HEIC`.

### Anti-Sleep (Управление сном)
- Нативное управление через `IOPMAssertion` (без зависших фоновых процессов).
- **Таймеры:** `∞` (бесконечно), `15m`, `30m`, `1h`, `2h`, `5h` с обратным отсчетом.
- Опция запрета сна при закрытой крышке (`pmset disablesleep`).
- Динамический значок в меню-баре с оставшимся временем.

### Network Bypass (VanyaVPN + SpoofDPI)
- **VanyaVPN:** 1-клик подключение/отключение системного VPN-сервиса через `scutil` и управление окном.
- **SpoofDPI:** Фоновый запуск SOCKS5-прокси (`127.0.0.1:1080`) и авто-конфигурация прокси для Wi-Fi.
- Отображение статусов в реальном времени (🟢 / 🔴).

### Легковесный Clipboard Manager
- Мониторинг буфера обмена (до 100 записей, сохраняется в компактный JSON < 50 КБ).
- **Глобальный хоткей:** `⌥⌘V` (Option + Command + V) — вызывает плавающее темное HUD-окно.
- **Клавиатурная навигация:**
  - Клавиши `1`–`9` — моментальная вставка соответствующего элемента.
  - Стрелки `↑` / `↓` + `Enter` — выбор и вставка.
  - `Esc` — закрыть окно.
  - `Clear History` — очистить историю (с защитой от случайного нажатия).
  - Закрепление (Pin) избранных записей.

### Low Power Mode (Режим энергосбережения)
- Мгновенное переключение режима низкого энергопотребления macOS (`pmset -a lowpowermode 0/1`) прямо из панели быстрых переключателей.
- Нативная интеграция через привилегированный хелпер `menutools-smc-helper` без лишних запросов пароля.
- Цветовая индикация состояния (желтый акцент в стиле macOS/iOS).

### iMessage Shortcuts (Навигация в Сообщениях)
Вынесено в **Settings → Messages Shortcuts**:
- Удобный переключатель активации функции.
- `↑` (Стрелка вверх) $\rightarrow$ переключение на **предыдущий** чат (`Ctrl+Shift+Tab`).
- `↓` (Стрелка вниз) $\rightarrow$ переключение на **следующий** чат (`Ctrl+Tab`).
- `⌥⌫` (Option + Delete) $\rightarrow$ быстрое **удаление** текущего диалога.
- Встроенные тесты и мониторинг разрешений (Accessibility, Input Monitoring, Keyboard Control).

### Window Controls / Traffic Lights (В стиле vorssaint)
Вынесено в **Settings → Window Controls (Traffic Lights)**:
- **Зеленая кнопка (Maximize):** Вместо создания отдельного виртуального рабочего стола (Spaces) окно быстро разворачивается на весь видимый экран и обратно при повторном клике (`zoom:`).
- **Красная кнопка (Quit on close):** Вместо оставления процесса приложения в Dock и фоне при закрытии окна, приложение полностью завершается (`terminate()`).
  - Режимы закрытия: *Last window only* (завершать только при закрытии последнего окна) или *Always quit* (завершать всегда).
- **Список исключений (Exclusions):** Гибкая настройка приложений, для которых сохраняется стандартное поведение macOS (по умолчанию: Finder, Desktop Services). Добавление запущенных программ в 1 клик или ввод bundle ID вручную.

### Системный монитор и быстрые утилиты
- **Монитор ресурсов:** Загрузка CPU %, используемая память RAM (GB / %), скорость загрузки и отдачи сети в реальном времени.
- **Управление кулерами:** Прямой доступ к AppleSMC, чтение температуры датчиков и настройка оборотов (Auto, по температурной кривой, фиксированные RPM).
- **IP-адреса:** Быстрый просмотр локального IP (Wi-Fi) и внешнего публичного IP.
- **Eject All Disks:** Безопасное извлечение всех внешних дисков и флешек.
- **Empty Trash:** Мгновенная очистка корзины.
- **Авто-сброс Google Drive:** Автоматическое отключение зависшего расширения `com.google.drivefs.finderhelper.findersync` при старте приложения.
- **16 стилей иконки Menu Bar:** Динамический круговой индикатор заряда батареи с адаптацией под Dark/Light тему, Apple Silicon CPU, кулер, инструменты, пламя, молния, куб и другие.

## Установка и запуск

### Сборка приложения:
```bash
make doctor
make release
```

### Установка в папку Программы (/Applications):
```bash
make install
```

### Создание .dmg установщика (для отправки другим пользователям):
```bash
make dmg
```
Образ появится по пути `build/MenuTools.dmg`.

Для ежедневной разработки доступны `make build`, `make release`, `make run`, `make dmg`, `make lint`, `make format` и `make preview`. Подробности — в [DEVELOPMENT.md](DEVELOPMENT.md).

### Разрешения (Accessibility, Input Monitoring):

Для перехвата кликов по кнопкам светофора (Window Controls) и шорткатов iMessage требуются разрешения **Accessibility** (Универсальный доступ), **Input Monitoring** и Keyboard Control. Их актуальный статус и кнопки мгновенного перехода/запроса находятся в **Settings → Permissions**. Разрешения следует выдавать установленной копии `/Applications/MenuTools.app`, а не временному исполняемому файлу из `.build`.

### Автозапуск при входе в систему:
В приложении перейдите во вкладку **Settings** $\rightarrow$ включите переключатель **Launch at Login**.
