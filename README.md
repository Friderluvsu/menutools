# 🛠️ MenuTools

**MenuTools** — это ультра-легковесный нативный macOS набор системных утилит и медиа-конвертер (замена Permute 4), живущий исключительно в строке меню (Menu Bar).

Написан на **чистом Swift 6 (AppKit + SwiftUI)**. Потребляет всего **~15–20 МБ RAM** (вместо 300+ МБ у Keyboard Maestro / Electron-утилит) и **0.0% CPU** в режиме ожидания.

---

## ✨ Возможности

### 1. 🔄 Permute Media Converter (Замена Permute 4)
- **Drag & Drop:** Перетаскивайте видео, аудио или картинки прямо в окно утилиты.
- **Видео:**
  - `MP4 (H.264 Universal)` — совместимо со всеми устройствами.
  - `MP4 (HEVC / H.265)` — максимальное сжатие при сохранении качества.
  - `MOV (Apple ProRes)` — для монтажа и мастеринга.
  - `WebM (VP9)` / `MKV`.
  - **Пресеты сжатия:** для Discord (< 25MB), Telegram (< 50MB) или сбалансированное.
- **Аудио:**
  - Извлечение звуковой дорожки из любого видео в 1 клик.
  - Конвертация в `MP3 (320k / 192k)`, `M4A/AAC (256k)`, `WAV (Lossless)` и `FLAC (Lossless)`.
- **GIF Maker:**
  - Создание высококачественных GIF из видео через двухпроходную генерацию палитры FFmpeg (без артефактов и "лесенок").
  - Пресеты: 640px (24 FPS), 480px (15 FPS), 320px (12 FPS), Original (30 FPS).
- **Изображения:**
  - Быстрая конвертация и сжатие: `WebP`, `PNG`, `JPG (90% / 70%)`, `HEIC`.

---

### 2. ☕️ Anti-Sleep (Управление сном)
- Нативное управление через `IOPMAssertion` (без зависших фоновых процессов).
- **Таймеры:** `∞` (бесконечно), `15m`, `30m`, `1h`, `2h`, `5h` с обратным отсчетом.
- Опция запрета сна при закрытой крышке (`pmset disablesleep`).
- Динамический значок в меню-баре с оставшимся временем.

---

### 3. 🌐 Network Bypass (VanyaVPN + SpoofDPI)
- **VanyaVPN:** 1-клик подключение/отключение системного VPN-сервиса через `scutil` и управление окном.
- **SpoofDPI:** Фоновый запуск SOCKS5-прокси (`127.0.0.1:1080`) и авто-конфигурация прокси для Wi-Fi.
- Отображение статусов в реальном времени (🟢 / 🔴).

---

### 4. 📋 Легковесный Clipboard Manager
- Мониторинг буфера обмена (до 100 записей, сохраняется в компактный JSON < 50 КБ).
- **Глобальный хоткей:** `⌥⌘V` (Option + Command + V) — вызывает плавающее темное HUD-окно.
- **Клавиатурная навигация:**
  - Клавиши `1`–`9` — моментальная вставка соответствующего элемента.
  - Стрелки `↑` / `↓` + `Enter` — выбор и вставка.
  - `Esc` — закрыть окно.
  - `Clear History` — очистить историю (с защитой от случайного нажатия).
  - Закрепление (Pin) избранных записей.

---

### 5. 💬 iMessage Shortcuts (Навигация в Сообщениях)
При активном приложении **Сообщения (Messages.app)**:
- `↑` (Стрелка вверх) $\rightarrow$ переключение на **предыдущий** чат (`Ctrl+Shift+Tab`).
- `↓` (Стрелка вниз) $\rightarrow$ переключение на **следующий** чат (`Ctrl+Tab`).
- `⌥⌫` (Option + Delete) $\rightarrow$ быстрое **удаление** текущего диалога.

---

### 6. ⚡️ Системный монитор и быстрые утилиты
- **Монитор ресурсов:** Загрузка CPU %, используемая память RAM (GB / %), скорость загрузки и отдачи сети в реальном времени.
- **IP-адреса:** Быстрый просмотр локального IP (Wi-Fi) и внешнего публичного IP.
- **Eject All Disks:** Безопасное извлечение всех внешних дисков и флешек.
- **Reset Google Drive:** Сброс зависшего расширения `com.google.drivefs.finderhelper.findersync`.
- **Empty Trash:** Мгновенная очистка корзины.
- **Flush DNS:** Очистка кэша резолвера DNS и перезапуск `mDNSResponder`.
- **Finder Tweaks:** Переключение показа скрытых файлов и авто-скрытия Dock в 1 клик.

## 🚀 Установка и запуск

### Сборка приложения:
```bash
make doctor
make release
```

### Установка в папку Программы (/Applications):
```bash
make install
```

Для ежедневной разработки доступны `make build`, `make run`, `make lint`, `make format` и `make preview`. Подробности — в [DEVELOPMENT.md](DEVELOPMENT.md).

### Разрешения для iMessage:

Для перехвата стрелок и отправки `Ctrl+Tab` нужны **Accessibility**, **Input Monitoring** и разрешение управления клавиатурой. Их актуальный статус и кнопки перехода находятся в **Settings → Permissions**. Разрешения следует выдавать установленной копии `/Applications/MenuTools.app`, а не исполняемому файлу из `.build`.

### Автозапуск при входе в систему:
В приложении перейдите во вкладку **Settings** $\rightarrow$ включите переключатель **Launch at Login**.
